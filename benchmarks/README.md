# Экспорт запросов для бенчмарка LLM-этапов

Сам бенчмарк живёт в отдельном репозитории **gmart-llm-bench** и запускается без gMART:
в нём лежат кейсы с проверками (`cases/*.yaml`), замороженные запросы к модели
(`data/requests.jsonl`) и раннер, который отправляет их в vLLM/Ollama и оценивает ответы.

Этот пакет нужен только для того, чтобы **заморозить запросы**: для каждого кейса этап
запускает код gMART (сборщик промпта, схему ответа, параметры вызова) против подставной
модели, перехватывает первый запрос к ней и записывает его в датасет. Ответ модели здесь не
нужен, сеть не используется.

```bash
# из корня gMART; gmart-llm-bench склонирован рядом
uv run python -m benchmarks list --bench ../gmart-llm-bench     # этапы и число кейсов
uv run python -m benchmarks export --bench ../gmart-llm-bench   # → data/requests.jsonl + manifest.json
uv run python -m benchmarks export --bench ../gmart-llm-bench --stages "orchestrator.*"
```

Перезапускайте экспорт, когда меняются промпты или схемы gMART либо `input` кейсов
(раннер помечает такие кейсы как устаревшие и не запускает их). Правка одних проверок
(`expect`) экспорта не требует. В `manifest.json` записываются коммит gMART и признак
незакоммиченных изменений.

## Устройство

- `stages/*.py` — этапы (`@stage`): какой код gMART и с какими аргументами строит запрос.
  Каждый этап — ровно один вызов модели. Последующая обработка ответа кодом
  (канонизация названий, clamp, repair-проходы, повторы при ошибке валидации) в бенчмарк
  не входит: он оценивает саму модель.
- `harness/capture.py` — `CaptureLlm`: записывает запрос и останавливает этап исключением,
  которое не ловят `except Exception` в сервисах.
- `harness/export.py` — прогон кейсов и запись датасета; `input_sha` связывает запрос
  с входом кейса.
- `harness/cases.py` — загрузка `cases/*.yaml` из каталога бенчмарка.

Новый этап: функция в `stages/` с `@stage("id", kind="auto"|"manual", ...)`, вызывающая код
gMART до запроса к модели, и кейсы в `cases/` бенчмарка. `auto` — ответ JSON, оценивается
только проверками; `manual` — свободный текст, нужен ещё взгляд человека.

Тесты: `uv run pytest tests/unit/test_benchmark_harness.py`.
