## Defects fixed during this check

- Control metadata and earlier requests appended to `scenario_data` tasks triggered indicator
  and base-scenario comparison routing. Retrieval now receives the actual task, with conditions
  in that task; the orchestrator retains the shared evidence for its own review.
- Scenario clarification and failed indicator validation were reported as completed evidence.
  Typed `clarification_required` / `pipeline_failed` events now reach the orchestrator; failed
  indicator pipelines retain failed status.
- Native `datetime` values in Urban API artifacts broke review JSON serialization and changed
  their representation on SSE replay. Evidence and buffered events now use the same JSON encoding.
- The reviewer could repeat an already completed data step by changing evidence references,
  or mark a fresh planned calculation complete without calling its specialist. Bounded review
  repair now rejects these decisions; unrepaired repetition produces an explicit stalled blocker.
