# Контракт чтения данных сценария

`ScenarioDataService` разделяет запросы о сохранённых показателях, выборку
сущностей конкретного типа и чтение справочников/карточек/связанных территорий.
Эти пути используют один каталог Urban MCP, но разные проверки результата.

- **Показатели:** явно названные в кавычках показатели связываются с полными
  названиями источника. «Население» и «Численность населения» не взаимозаменяемы.
  Значения, единицы, отсутствие данных, разницы и проценты формируются из
  подтверждённых записей, отдельно для каждого доступного сценария.
- **Сущности одного типа:** физические типы и типы сервисов сопоставляются
  раздельно, если пользователь явно указал домен. Полная пустая выборка
  подтверждает ноль; она не запускает поиск в окружении. Карта проверяется
  по тому же множеству идентификаторов, что список сущностей.
- **Общее чтение:** `UrbanReadWorkflow` предоставляет модели полное семейство
  инструментов нужной области. План состоит максимум из четырёх чтений.
  Все аргументы проверяются до MCP: область, подтверждённые ID, типы и enum,
  явно заданные годы и источники. Ошибка выбора не разрешает переход в другую
  область. Данные источника не передаются модели для повторного сочинения ответа.
  Пустой план проходит ограниченную повторную проверку модели; он не считается
  доказательством отсутствия данных. Обычный список сущностей сценария читает
  источник сущностей: несколько геометрий одного объекта не создают лишних строк.

Карточка объекта с полями `geometry` и `properties` остаётся карточкой.
Только запись с `type=Feature` разворачивается как GeoJSON Feature. Нулевые
значения сохраняются; вложенный JSON не обрезается посреди значения.

Полные результаты более 1000 строк публикуются несколькими таблицами с номерами
частей. Запрос первой страницы сохраняет пагинацию и признак неполноты. Для
запроса всей коллекции читаются последующие курсоры с неизменными фильтрами;
повтор курсора, превышение 100 страниц или несовпадение итогового количества
не считаются подтверждённым полным результатом.

Ошибка источника возвращается как недоступность данных, а не как ноль.
Временные ошибки транспорта HTTPX/AnyIO, включая исключения без сообщения,
допускают не более двух повторов чтения. Проверяется и причина обёрнутого
исключения; ошибки параметров и запрет доступа не повторяются.
Истечение токена сохраняет прежнюю обработку авторизации. Выполнение плана
не создаёт и не изменяет объекты Urban API.

Регрессии находятся в `tests/unit/test_scenario_data_audit_regressions.py`,
`tests/unit/test_scenario_data_read.py`, `tests/unit/test_scenario_data_transport.py`
и существующих тестах `scenario_data`.
Массовые реальные проверки сохраняются отдельно в локальной папке `benchmarks`,
чтобы токены и пользовательские данные не попадали в репозиторий.
